# Rivet iOS

Native iOS app for [Rivet](https://github.com/PavluninVladimir/rivet), an
orchestrator for autonomous software development with AI coding agents. The
app is meant for following Epics and tasks and answering escalations from a
phone. There is no code yet: the repository only reserves the place for the
client. Documentation is in Russian.

Нативное iOS-приложение [Rivet](https://github.com/PavluninVladimir/rivet) —
оркестратора автономной разработки с помощью AI-агентов: наблюдение за
Epic'ами и задачами, ответы на эскалации (needs attention) с телефона.

Код ещё не создан. Бэкенд и описание всего проекта — в
[основном репозитории](https://github.com/PavluninVladimir/rivet), рабочий
клиент сегодня — веб-консоль
[rivet-web](https://github.com/PavluninVladimir/rivet-web).
